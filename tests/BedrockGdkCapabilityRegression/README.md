# GDK 构建能力回归

在仓库根目录使用 `global.json` 指定的 SDK 执行：

```powershell
dotnet run --project tests/BedrockGdkCapabilityRegression -c Release
```

宿主直接编译生产 GDK 解包入口及安装服务，使用独立的 Secrets 替身：缺失值、短数组和合成的 48 字节数组。不读取生产 Secrets、环境密钥、账号或真实安装包，不启动游戏，也不执行真实解密。

测试覆盖正式版和预览版能力独立、缺失组件的专门错误分类、安装前预检、原有文件与模组保留，以及取消优先级。形状合格的合成值仅用于确认代码继续检查不存在的测试包；它不代表真实内容密钥有效。清理仅限已验证位于系统临时目录下的 GUID 测试根。

此回归锁定的是“构建不具备能力时提前识别并保护安装状态”。实际解包仍需要维护者提供包含正确内容组件的构建，测试通过不能代替真实安装包验收。
